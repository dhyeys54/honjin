# The Honjin name and icon

Honjin's code is MIT-licensed: you can use, change, fork and sell it (see [LICENSE](LICENSE)). The MIT licence covers
the code only. It does not cover the name "Honjin" or the Honjin icon in `branding/`.

**You may, without asking:**
- Say your project is "based on Honjin", "a fork of Honjin" or "compatible with Honjin".
- Use the name and icon to refer to the official Honjin project, for example in articles, videos or a list of tools.
- Build Honjin from this repository for your own use, or for your team, without changing its name.

**Please don't, without written permission:**
- Distribute a modified build, or a fork, under the name "Honjin" or with the Honjin icon. Give it its own name and
  icon.
- Use the name or icon in a way that suggests the project endorses you or your product.

The official builds are the ones published at https://github.com/dhyeys54/honjin/releases.

Questions or permission requests: open a [Discussion](https://github.com/dhyeys54/honjin/discussions).
